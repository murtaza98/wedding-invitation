 WORKFLOW FOR ADDING ANY GEMINI IMAGE
────────────────────────────────────────────────────────────────────────────────

 1. Generate in Gemini (or Imagen) using the prompt above
 2. Save to public/<filename>.png or public/<filename>.jpg
 3. Update src/config.js or the relevant CSS to reference the file
 4. Run:  node tools/shoot-both.mjs
          → /tmp/envelope-desktop.png  (1440×900)
          → /tmp/envelope-mobile.png   (430×932)
 5. Review screenshots; adjust CSS if needed
